Welcome to HireForge. This is your all-in-one tool for building, refining, and generating job-ready materials.

Use the sections above to create your profile, add work experience, organize skills, and track certifications and awards. When you're ready, you can generate a polished resume, craft a tailored cover letter, or create a professional thank-you note which can then be sent to recruiters/interviewers after an interview.

Tip: Start with your profile, be sure to add your Google Gemini API key, then add jobs and bullet points before generating your resume.

Why HireForge Exists

HireForge was built as a final project for CSC3100 with a simple goal: make resume building less painful and more structured for students like myself. It, however, has grown into much more. I thoroughly enjoyed building this and have pushed it beyond the requirements.

Instead of starting from scratch, this tool helps you organize your experience, skills, and achievements into reusable building blocks, then generate a resume, cover letter, or thank-you note tailored for recruiters and interviewers.

Built With
  • Frontend: HTML, Bootstrap (Flatly theme), vanilla JavaScript
  • Backend: Node.js + Express
  • Storage: SQLite
  • AI features: Google Gemini API (user-provided key required)

Built with open-source libraries.
